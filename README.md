# Task 3 - Interactive Sales Dashboard

## Project Overview

This project is developed as part of the ApexPlanet Data Analytics Internship - Task 3.

The main objective of this task is to analyze sales data and create an interactive dashboard using Microsoft Power BI.

## Objective

- Analyze sales performance.
- Visualize sales data using different charts.
- Identify sales patterns and trends.
- Create an interactive dashboard using slicers and KPI.

## Tools Used

- Microsoft Power BI Desktop
- Microsoft Excel
- VS Code (for documentation)

## Dataset

The sales dataset is provided in the Excel file:

`ApexPlanet_DataAnalytics.xlsx`

The dataset is used as the source for creating the Power BI dashboard.

## Dashboard Features

The dashboard contains:

- Total Sales KPI
- Sales by Category
- Sales by Gender
- Sales by City
- Sales by Year
- Category Slicer
- City Slicer

## Dashboard

The Power BI dashboard provides an interactive view of sales performance.

Users can select different categories and cities using the slicers, and the dashboard visuals update accordingly.

## Files Included

- `README.md` - Project documentation
- `ApexPlanet_DataAnalytics.xlsx` - Sales dataset
- `Task_3_Sales_Dashboard.pbix` - Power BI dashboard project

## Conclusion

The interactive Power BI dashboard provides a simple and effective way to analyze sales data and understand sales performance across different categories, cities, genders, and years.
